# Azone 商品 ID 替换助手（Chrome 插件版）

这是唯一保留的版本：**Chrome 浏览器插件**。

插件用于在已打开的 Azone 商品页里直接替换加购区域的商品 ID/JAN 码，并提供两个按钮：

1. **替换ID**：只替换当前页面 DOM 里的 ID/JAN，不刷新页面。
2. **自动添加购物车并去结算**：替换 ID → 设置数量 → 点击商品页加购按钮 → 快速进入购物车 → 自动点击购物车页的“レジに進む / 進行結算”按钮，让页面尽快到达购买确认/结算页面。

> 重点：替换 ID 本身不会刷新或重新加载页面。自动结算流程会按你的点击主动跳转，但插件会隐藏购物车页并尽快点击结算按钮，避免长时间展示购物车页面。

## 安装 Chrome 插件

1. 打开 Chrome：`chrome://extensions/`
2. 打开右上角「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择本仓库里的 `chrome_extension` 文件夹
5. 打开 Azone 商品页后，点击浏览器右上角插件图标

## 使用方法

1. 打开 Azone 商品页，例如：

```text
https://www.azone-int.co.jp/azonet/item/4573199845111
```

2. 点击插件图标。
3. 在「目标商品 ID / JAN 码」中输入你要替换成的 ID，例如 `4573199853154`。
4. 输入数量，例如 `3`。
5. 如果只想改当前页面 ID，点击「替换ID」。
6. 如果想直接抢购，点击「自动添加购物车并去结算」。插件会尽快跳过购物车展示，直接到购买确认/结算页面。

## 插件做了什么

- `chrome_extension/manifest.json`：Chrome Manifest V3 配置，只作用于 `https://www.azone-int.co.jp/azonet/*`。
- `chrome_extension/popup.html` / `popup.js`：提供商品 ID、数量输入框，以及「替换ID」「自动添加购物车并去结算」两个按钮。
- `chrome_extension/content.js`：替换 `item_cnt_<商品ID>`、`data-jancode` 等 DOM 属性，点击加购按钮；进入购物车页时会隐藏购物车页并高频查找/点击“レジに進む / 進行結算”。

## 注意事项

- 请在遵守网站服务条款和当地法律前提下使用。
- 如果页面本身没有加购按钮或数量框，插件不会通过刷新去等待它出现。
- 如果 Azone 后续修改页面结构，可能需要调整 `content.js` 中的匹配规则。
